APPLICATIONS

- / and /call/ contain the call-first Marisol experience.
- /chat contains the original chat and voice-chat experience.
- src/call contains the call-first frontend.
- src/chat contains the original frontend.
- src/shared contains shared components and foundations.
- api contains the Vercel serverless handlers.
- server/index.js contains the equivalent Express routes used locally.

LOCAL DEVELOPMENT

Run the API and frontend in separate terminals:

npm run dev:api
npm run dev

Frontend: http://localhost:5173
API: http://localhost:3000

Vite proxies /api requests to the Express server on port 3000.

BACKEND ENDPOINTS

GET /api/config
Returns feature availability for TTS, live voice, and personalized readings.

POST /api/tts
Body: { "text": "Text Marisol should speak" }
Returns ElevenLabs audio as audio/mpeg.

POST /api/call-reading
Body:
{
  "name": "Elena",
  "area": "Family",
  "change": "What the user hopes will change",
  "desire": "What the user wants most"
}
Returns a guarded personalized reflection or the scripted fallback.

POST /api/reading
Body: { "name": "Elena", "userText": "User response" }
Used by the original chat journey.

GET /api/voice-token
Returns an ElevenLabs Conversational AI signed URL when an agent is configured.

IMPORTANT NOTES

- The call-first demo uses scripted ElevenLabs TTS; it is not a WebRTC call.
- Mobile audio begins after a real user gesture because iOS blocks automatic playback.
- Personalized readings deliberately fall back to scripted content if Anthropic is unavailable.
- Keep api serverless handlers and server/index.js behaviorally aligned.
- Coordinate before changing API request or response contracts because the frontend consumes them directly.
